# Unity project context

This repository is an audit baseline, not a runnable game. It retains the
upstream Unity 2022.3.5f1 C# systems and package/project configuration, but no
scenes or content assets. See `Docs/SourceAudit.md` for confirmed systems,
license boundaries, Unity 6000 compatibility status, and source commit.

No Unity MCP provider was found in the source configuration. No Unity editor,
build, test, migration, or asset import was run for this baseline.
